# Alerts وDoctor Messages

تم تنفيذ شاشة Alerts وربطها بمستندات مجموعة `alerts` التي تحمل `userId` للمستخدم الحالي. تعرض الشاشة عنوان التنبيه، الرسالة، مستوى الخطورة، حالة القراءة، وتسمح بتعليم التنبيه كمقروء.

تم تنفيذ شاشة Doctor Messages لتطابق شاشة الرسائل في مرجع Figma من حيث البطاقات والحالات. الرسائل الحالية نقطة واجهة أولية، وسيتم ربطها لاحقًا بمجموعة `messages` بعد اعتماد نموذج مشاركة الرسائل وموافقة المريض.

قواعد Firestore الحالية تقصر قراءة التنبيهات على صاحبها أو الطبيب، وتسمح بتحديث حالة القراءة لصاحب التنبيه فقط.
