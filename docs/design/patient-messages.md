# Patient Messages

تمت إضافة شاشة Messages إلى Profile للمريض. تقرأ الرسائل الواردة من مجموعة `messages` باستخدام `recipientId`، وتعرض المحادثة بتمييز رسائل الطبيب عن ردود المريض.

يمكن للمريض الرد مباشرة، ويحفظ الرد بنفس نموذج الرسائل باستخدام UID المريض كمرسل وUID الطبيب كـrecipient. عند عدم وجود رسائل، تعرض الشاشة حالة فارغة ولا تسمح بإرسال رد قبل وصول رسالة من طبيب مرتبط.

تدفق الوصول الحالي هو:

```text
Patient Profile → Messages → قراءة الرسائل والرد
```

قواعد Firestore تقصر القراءة على المرسل أو المستقبل، وتسمح بإنشاء الرسالة للمستخدم المسجل فقط.
