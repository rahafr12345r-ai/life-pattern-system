# Risk Assessment

يحفظ ناتج محرك التحليل في:

```text
risk_assessments/{userId}/daily/{YYYY-MM-DD}
```

الحقول المتوقعة هي `score` من 0 إلى 100، و`level` بقيمة `low` أو `medium` أو `high`، و`factors`، و`recommendation`، و`createdAt`.

تقرأ Patient Home أحدث نتيجة وتعرض الدرجة ومستوى الخطر بدل قيمة وهمية. إذا لم توجد نتيجة محفوظة، تستمر الشاشة في عرض حالة عدم وجود تقييم. قواعد Firestore تسمح للمستخدم بقراءة تقييمه، وللطبيب بقراءة تقييمات المرضى وفق حسابه، بينما لا يكتب التقييم إلا المستخدم في النسخة الحالية.

المرحلة التالية لربط الإنتاج هي إضافة خدمة خادم موثقة تستدعي محرك التحليل بعد وصول سجلات اليوم، ثم تكتب النتيجة إلى هذا المسار وتُنشئ Alert عند المستوى العالي.
