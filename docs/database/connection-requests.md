# Connection requests

يستطيع المريض من Profile إدخال Doctor ID وإرسال طلب ربط. يحفظ الطلب في:

```text
patient_therapist_links/{patientId}_{doctorId}
```

تبدأ الحالة `pending`. يظهر الطلب للطبيب في Connection requests، ويمكنه اختيار Accept أو Reject. عند القبول تصبح الحالة `accepted`، وعند الرفض تصبح `rejected`.

تم تحديث قواعد الرسائل بحيث لا تُقرأ الرسائل إلا إذا وُجد رابط مقبول بين الطرفين. إنشاء الطلب متاح للمريض أو الطبيب المسجل، وتحديث الحالة متاح للطرفين المرتبطين.

هذا التدفق يمنع بدء المراسلة قبل وجود موافقة صريحة من الطبيب على طلب المريض.
