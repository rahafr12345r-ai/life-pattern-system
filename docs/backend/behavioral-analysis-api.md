# Behavioral analysis API

تمت إضافة endpoint:

```text
POST /v1/analysis/behavioral
```

يستقبل من 1 إلى 30 ملاحظة يومية، وكل ملاحظة تحتوي اليوم والمزاج وساعات النوم وعدد الخطوات. يعيد endpoint درجة من 0 إلى 100، ومستوى `low` أو `medium` أو `high`، والعوامل المؤثرة، وتوصية متابعة، وعدد الملاحظات.

القواعد الحالية تفسيرية وليست تشخيصًا طبيًا: المزاج المنخفض يرفع الدرجة، والنوم الأقل من ست ساعات يرفعها، والنشاط الأقل من 3000 خطوة يرفعها. المستوى العالي يوصي بمراجعة النمط مع فريق الرعاية، ولا يرسل تنبيهًا طبيًا تلقائيًا.

قبل ربط endpoint بتدفق Firebase الإنتاجي يجب إضافة مصادقة الخادم والتحقق من أن UID يملك الملاحظات المطلوبة، ثم حفظ النتيجة في `risk_assessments/{userId}/daily/{dayId}`.
