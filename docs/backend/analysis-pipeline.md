# Daily analysis pipeline

تم توحيد الخطوات في `run_daily_analysis`: تستقبل الملاحظات اليومية، تمررها إلى المحرك التفسيري، ثم تحفظ Risk Assessment وتُنشئ Alert عند `high`.

الخط يستخدم معرفًا ثابتًا للتقييم والتنبيه حسب `userId` و`assessment_day`، لذلك إعادة تشغيل العملية آمنة ولا تنتج تنبيهات مكررة. طبقة Firestore تُحقن في الخط، مما يسمح باختباره دون الاتصال بقاعدة حقيقية.

في الإنتاج يجب استدعاء الخط من مهمة موثقة بعد اكتمال بيانات اليوم، مع تمرير UID صادر من جلسة Firebase وليس قيمة يرسلها العميل بحرية. يجب أيضًا تهيئة Firebase Admin عبر Service Account محفوظ في البيئة الآمنة.
