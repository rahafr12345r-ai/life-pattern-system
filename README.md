# Life Pattern System — نظام النمط الحياتي

مشروع تخرج لبناء نظام ذكي لتحليل أنماط الحياة والمراقبة السلوكية المبكرة.

## التقنيات المعتمدة

- Flutter / Dart
- Python / FastAPI
- Firebase Firestore
- Firebase Authentication
- Firebase Cloud Messaging
- HealthKit / Health Connect
- Git / GitHub
- Manual, unit, and functional testing

## بنية المستودع

- `mobile_app/`: تطبيق Flutter للمستخدم ولوحة المعالج.
- `backend/`: خدمة FastAPI ومحرك التحليل.
- `docs/`: المتطلبات، المعمارية، API، قاعدة البيانات، التصميم والاختبارات.
- `PLAN.md`: خطة المراحل والقرار التقني.
- `ideas.md`: موجز التصميم المعتمد من Figma.

## الحالة الحالية

تم تنفيذ إعداد المرحلة الأولى مبدئيًا: هيكل المجلدات، التوثيق، وجرد شاشات Figma. Flutter SDK غير متوفر في بيئة Sandbox الحالية، لذلك لم يتم الادعاء بتشغيل أو اختبار تطبيق Flutter بعد.

لا تنتقل إلى Firebase أو API أو تحليل السلوك أو تنفيذ الواجهات قبل تأكيد اكتمال المرحلة الأولى.
